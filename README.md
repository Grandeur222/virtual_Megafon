This is a virtual megafon for windows. So microfon sounds direcly directing the speaker . Also app can be 10s records and ecolayzer   

1- Select the input microphone device ( reconmended for external microphone ) 
2- Select the output device
3- Set up the ecolayzer 

- Ecolayzer settings can be save with profiles

- 10s-record file default selected in user\music\Megafon (it changeable)

!Important notes

-Keep the microphone away from the speaker or position it at an angle.
-You can use the 10-second recording feature to test your equalizer settings.
-4 languages ​​are supported (English, Turkish, French, Russian).
